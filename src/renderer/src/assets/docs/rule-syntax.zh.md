# 规则语法

千语集里凡是写「规则」的地方——音变规则集、正字法、文字映射、构形里的微调、语素异体形的环境——都用同一套写法（沿用音变姬的规则格式）。先讲一条规则长什么样，最后列出各处怎么用。

## 一条规则 {#rule}

```
目标 > 替换 / 环境 , 环境 … - 排除环境 , 排除环境 …
```

- **目标**：要改的部分。留空表示在环境处**增生**（`> e / #_CC`）。
- **替换**：改成什么。留空表示**删除**（`h > / V_V`）。
- **环境**：`_` 是目标所在的位置，左边写它前面要有什么，右边写后面要有什么；两边都可以留空，但 `_` 不能省。没有 `/` 就是任何位置都改。几个环境用 `,` 隔开，依次应用。
- **排除**：`-` 后面写的环境里不改（`p > pp / V_V - _#`）；几个排除用 `,` 隔开，落在任何一个里都不改（`p > b / V_V - a_a , o_o`）。

规则从上到下依次应用，每条规则在整个词里从左到右反复匹配。`;` 到行尾是注释。

## 音类 {#classes}

| 写法 | 意思 |
|---|---|
| `V=aeiou` | 单个大写字母的音类，成员按字符拆 |
| `{Vlong}=ā ē ī ō ū` | 长名字的音类，成员用空格或逗号分隔 |
| `[ptk]` | 临时音类，直接写在规则里 |
| `th\|θ` | 多合字母：匹配时把 th 当成一个单位 |
| `[+送气] = ph th kh` | 特征：从这一行起，规则里可以写 `[+送气]`、`[-送气]`（见下面「特征」） |
| `ˈ = -2 , -3` | 重音规则：到这一行时给词标上重音（见下面「重音规则」） |
| `-* 名字` | 阶段快照：记下此刻的词形 |
| `-@ 规则集名 : 阶段 .. 阶段` | 引用另一套音变的一段，就在这里跑（见下面「引用别的音变」） |

音系页里定义的音类、多合字母在各处自动可用；规则文本里同名的声明会覆盖它们。

## 位置记号 {#symbols}

| 写法 | 意思 | 例子 |
|---|---|---|
| `#` | 词首（写在左边）或词末（写在右边）；输入有空格时每个词各算各的（构形流水线里整个形式算一个词） | `V > / _#` 词末元音脱落 |
| `C`、`V`、`{名字}`、`[ptk]` | 这个音类里**任意一个**；每写一次各算各的 | `_CC`：后面是**任意两个**辅音 |
| `C1`、`C2`、`V1`… | 带编号的音类：**同一条规则里编号相同就是同一个音** | `_C1C1`：后面是**同一个辅音写两遍** |
| `σ` | 音节边界：两个音节之间，词首、词尾、`·` `-` 这类分隔符两边也算（见下面「音节边界」） | `d > t / _σ` 音节末的 d 清化 |
| `ˈ`、`ˌ` | 重读、次重读音节的开头（先要有重音规则标上） | `a > aː / ˈ(C)(C)_` 重读音节里的 a 延长 |
| `[+送气]`、`[-送气 +塞]` | 特征：有 / 没有这个特征的音，几个写在一起取交集 | `a > e / [+送气]_` |
| `(x)` | 可有可无 | `#(C)V_` |
| `x\|y` | 二者之一 | `#\|C_` 词首或辅音后 |
| `?` | 中间隔着任意多个音（写在环境里；目标、替换里的 `?` 见下面「满足 / 不满足环境」） | `A > e / Front?_` |
| `@名` | 语素（按 gloss 或形式），成员是它的全部异体形 | `@复数 > @复数弱 / V_` |
| `t.h` | 用点隔开，防止被当成多合字母 | |
| `¢` | 复合词内部的边界（普通符号，用完删掉：`¢ > / _`） | |
| `\?`、`\.`、`\#`、`\C`、`\σ`… | 反斜杠加一个符号：就是这个字符本身，不当规则符号，也不当音类（希腊字母 σ 本身写 `\σ`） | `\? > ⸮` 把问号换成文字里的问号 |

编号只在一条规则里算：`C1C2` 是两个辅音（可以相同也可以不同），`C1VC1` 是「辅音—元音—同一个辅音」。

## 替换里的写法 {#replacement}

| 写法 | 意思 | 例子 |
|---|---|---|
| 音类对音类 | 目标里的第一个音类与替换里的音类按位置对应 | `[ptk] > [bdg] / V_V` |
| 特征对特征 | 同样按位置对应：`[+送气] = ph th kh`、`[-送气] = p t k` 都列了成员时 | `[+送气] > [-送气] / _#` |
| `C1`… | 输出目标或环境里同编号音类匹配到的那个音 | `C1C1 > C1` 双写辅音变单写 |
| `\` | 换位（两个以上字符整体倒序） | `bm > \ / _` |
| `2` | 目标写两遍 | `p > 2 / V_V` |
| 留空 | 删除 | `h > / V_V` |

## 满足 / 不满足环境 {#ifelse}

目标、替换里写一个 `?`，一条规则就分成两路：`?` 前面是**满足**环境时怎么改，后面是**不满足**时怎么改。

| 写法 | 意思 | 例子 |
|---|---|---|
| `x > a?b / 环境` | 满足环境的 x 改成 a，其余的 x 改成 b | `p > b?f / V_V`：元音之间的 p 变 b，别处的 p 变 f |
| `x1?x2 > a?b / 环境` | 满足环境的 x1 改成 a；不满足环境的地方，x2 一律改成 b | `t?d > s?z / _i`：i 前面的 t 变 s，不在 i 前面的 d 变 z |
| `x1?x2 > a / 环境` | 满足时 x1 改成 a，不满足时 x2 改成 a | `p?b > f / V_V` |

- a、b 可以是任何替换写法：音类对应（`[ptk] > [bdg]?[fθx] / V_V`）、`\` 换位、`2` 双写、留空删除。满足时换位写成 `\?2`（不满足时双写）。
- 「满足」是对上了环境里的任意一个、又不在排除里；其余位置都算「不满足」。
- 两路都按这条规则改之前的词判断、一次改完，一路改出来的东西不会再被另一路改；同一处两路都对得上时按满足那一路。
- 目标、替换里各只能有一个 `?`；环境里的 `?` 仍是「隔着任意多个音」。要写问号本身用 `\?`。
- 不写环境时处处都算满足，`?` 后面那一路用不上（会有提示）。

## 音节边界 σ {#syllables}

规则里写 `σ` 表示「这里是音节边界」。匹配前先把词划成音节，σ 对上的是音节和音节之间；词首、词尾，以及 `·` `-` `‿` `=` 这类分隔符的两边也都算边界。没写 σ 的地方照常匹配，不受音节影响。

音节怎么划：用这门语言在音系页「音节与韵律」「配列」里的设置——音节核是元音音位、名为 V 的音类或配列里的音节核（规则文本里自己定义的 V 也算），辅音尽量划给后一个音节的起首，受「合法起首」表和音节模板限制；多合字母（`th|θ`）、音位表里的多字母音位（`ts`、`aɪ̯`）算一个音；拼写里认不出的字母按 IPA 表推断是不是元音，所以正字法规则写到一半、还是拼写的时候也划得出来。

| 写法 | 意思 |
|---|---|
| `d > t / _σ` | 音节末的 d 清化（词尾也是音节末）：ad.ma → at.ma，ad → at |
| `k > g / σ_` | 音节首的 k 浊化 |
| `V > Vː / _σ` | 开音节里的元音延长（元音后面紧接着就是音节边界） |
| `> ə / Cσ_C` | 跨音节的两个辅音中间插 ə：ak.ta → akəta |
| `s > h / _σC` | 音节末、后面接辅音的 s 变 h |
| `h > / σ_` | 音节开头的 h 脱落 |

- 同一条规则里可以写几个 σ：`a > e / σC_Cσ` 是「一个闭音节 CVC 里的 a」。
- 音节是按规则那一步的词形划的：前面的规则改了词，后面用 σ 的规则按改过的重新划。
- 要写希腊字母 σ 本身，写 `\σ`。

## 重音规则 {#stress}

一行 `ˈ = 条目 , 条目 , …` 是重音规则：词走到这一行时，按条目挑一个音节，在它前面标上 `ˈ`。标上的重音跟着词往下走，后面的规则照常匹配（音和音之间隔着 ˈ 也对得上），被换掉的那段里原有的 ˈ 按原来的位置放回去；直到下一条重音规则，再按新的规则重新标。测试台的每个阶段、每一列都带着重音记号。

| 写法 | 意思 |
|---|---|
| `ˈ = …` | 主重音；先去掉词里原有的重音记号再标（打不出 ˈ 可以写 `'`） |
| `ˌ = …` | 次重音；主重音不动，挑中的音节已经是主重音时不标 |
| `ˈ =` | 什么都不写：去掉重音，后面不再带重音 |

**条目**从左往右试，第一条对上的算。一条写成 `<词类> (音节数) 位置 音节核 / 环境 - 排除`，除了位置都可以省：

| 部分 | 写法 | 意思 |
|---|---|---|
| 词类 | `<名词>`、`<名词\|形容词>`、`<!动词>` | 只对这些词类的词（开头 `!` 是「不是这些」）；词库、语素里勾了「对重音影响 → 传递词性」的词才带着词类，没带的这一条不看 |
| 音节数 | `(2)`、`(3+)` | 这个词恰好 2 个音节、至少 3 个音节时才看这一条 |
| 位置 | `1`、`2`、`-1`、`-2`、`-3` | 第 1、2 个音节，倒数第 1、2、3 个音节 |
| | `0` | 不重读 |
| | `*`、`-*` | 从前、从后找第一个合条件的音节 |
| 音节核 | `{双元音}`、`[áéí]`、`Vː` | 这个音节的核里有它（核是相邻元音连起来的那一段：ái 里有 á） |
| 环境 | `/ _CC`、`/ σC_` | `_` 是音节核；`_CC` 是核后面接着两个辅音（跨过音节边界也算） |
| 排除 | `- #_` | 对上排除环境的不算 |

- 没有写条件的条目，词不够长时落到最近的一头：单音节词的「倒数第三个音节」就是它自己。写了条件的条目，词里没有那个位置就跳过。
- 单独一条 `@`（一般放在最前面）：词库、语素里勾了「对重音影响 → 传递特殊重音」的词，整个词按那里标的音节重读（标成不重读的就不标），其余条目都不看；没标的词照常往下试。
- 词条的词类、特殊重音在自动标音、整库演化、构形的「音变」步骤里都会带上（构形里加了词缀，特殊重音跟着挪，重读的词缀改到词缀上）；音变测试台里敲的词，对上这门语言里勾了「对重音影响」的词条或语素（去掉连字符比）时也带上。
- 在末尾写 `| 分隔符 段`：按这些分隔符把词分成几段各算各的，主重音落在第几段（`1` 第一段、`-1` 最后一段），其余段是次重音。`| · -1` 就是「复合词各词分开算，主重音在最后一个词上」。

| 想要的重音 | 写法 |
|---|---|
| 固定在第一个音节 | `ˈ = 1` |
| 倒数第二个音节 | `ˈ = -2` |
| 拉丁式：倒数第二个音节是长音节（核是长元音，或后面接着两个辅音）就重读它，否则倒数第三 | `ˈ = -2 {长元音} , -2 / _CC , -3` |
| 最左边的长元音，没有就第一个音节 | `ˈ = * {长元音} , 1` |
| 最右边的闭音节，没有就最后一个音节 | `ˈ = -* / _Cσ , -1` |
| 标了锐音符的音节优先，双音节词看第二个音节有没有双元音 | `ˈ = * [áéíóú] , (2) -1 {双元音} , (2) 1 , -3` |
| 复合词每个词各算，主重音在最后一个词 | `ˈ = -2 , -1 \| · -1` |
| 音节很多的词，第一个音节带次重音 | 主重音之后另起一行 `ˌ = (4+) 1` |
| 动词重读最后一个音节，其余倒数第二 | `ˈ = <动词> -1 , -2` |
| 代词、小品词不重读 | `ˈ = <代词\|小品词> 0 , 1` |
| 个别词的重音特殊 | 在词条里勾「对重音影响 → 传递特殊重音」标上音节，规则写 `ˈ = @ , -2` |

规则里用重音：`ˈ` 对上的是重读音节的开头（ˈ 标在音节第一个音前面），`ˌ` 是次重读音节。

| 写法 | 意思 |
|---|---|
| `a > aː / ˈ(C)(C)_` | 重读音节里的 a 延长（起首最多两个辅音） |
| `V > ə / σ(C)(C)_ - ˈ(C)(C)_` | 非重读音节里的元音弱化成 ə |
| `ˈ > ` | 去掉重音记号（跟 `ˈ =` 一样，但只在这一步） |

音系页「音节与韵律」的重音位置选「自定义重音规则」时，写的就是 `=` 后面那一截（`-2 {长元音} , -2 / _CC , -3`），测试和词库样例按它标重音；音标里已经带 ˈ 的（正字法规则里标过的、手填的）照记号来。

## 引用别的音变 {#include}

两套音变有一段是共用的（比如两门姊妹语都从同一个祖语的同一段变化走过来），不用复制粘贴：写一行

```
-@ 规则集名 : 起始阶段 .. 终止阶段
```

跑到这一行时，就把那套音变里从「起始阶段」到「终止阶段」之间的规则原样跑一遍。冒号和阶段都可以不写（`-@ 规则集名`），那就是整套。

- 那边改了，引用它的这边跟着变——共用的那段只维护一处。
- 引用来的阶段在这边也算数：测试台、构形的「音变」步骤、词条的历史形式都能挑到它们；跟自己这边同名的阶段算作同一个。
- 被引用的那套按**它自己**绑定的语言解析：它的音类、多合字母用它自己的，不受这边影响。
- 引用可以套引用（最多四层），转着圈引用会直接报错；规则集改了名字，引用那一行要跟着改。

## 特征 {#features}

一行 `[+特征名] = 成员 成员 …` 定义一个特征，成员用空格隔开（`ph` 是一个成员）。从这一行起，规则里写 `[+特征名]` 表示「有这个特征的任意一个音」，写 `[-特征名]` 表示没有的。

| 写法 | 意思 |
|---|---|
| `[+送气] = ph th kh` | 定义「送气」 |
| `[-送气] = p t k` | 也可以列出「不送气」的成员；没列时 `[-送气]` 指送气音以外的任何一个音 |
| `a > e / [+送气]_#` | 送气音后面的词尾 a 变 e |
| `[+送气] > [-送气] / _C` | 辅音前的送气音变成对应的不送气音（两边都列了成员，按位置对应） |
| `i > / [+浊 -鼻]_#` | 几个特征写在一个方括号里取交集：浊的、又不是鼻音的音后面 |

- 特征跟音类的区别：音类在整段规则里都有效；特征**按行生效**，写在哪一行就从哪一行起能用，后面可以重新定义——比如一条音变把 ph 变成了 f，之后写一行 `[+送气] = th kh`。
- 引用还没定义的特征会有提示，那一处什么也匹配不到。
- 方括号里是 `+名` 或 `-名` 这种写法时才是特征；`[ptk]`、`[^aeiou]`、`[a-z]` 仍是临时音类。

## 各处怎么用 {#places}

### 音变规则集、正字法、文字映射

上面的写法都能用。文字映射里单独一行 `@glyphs` 会展开成字形表自动生成的对应；字形的转写值里有 `?` `.` `#` 这类符号时，展开时自动加上反斜杠，按字面对应。

### 语素的异体形环境 {#allomorph}

只写环境那一截，`_` 就是这个语素本身：

- **后缀**看前面的词干结尾：`V_` 在元音后、`C1C1_` 在双写辅音后。
- **前缀**看后面的词干开头：`_d` 在 d 前、`_Vr` 在「元音 + r」前、`_CC` 在任意两个辅音前、`_C1C1` 在双写辅音前。
- 从上往下挑第一条对得上的；环境留空的那条是默认形。

### 构形流水线的「微调」{#adjust}

每行一条规则，例如 `at > / _#`、`> u / _#`。另有四个按字面写的简写（不认音类）：

| 简写 | 等于 |
|---|---|
| `-at` | `at > / _#` 去掉词尾 at |
| `+u` | `> u / _#` 词尾加 u |
| `^-e` | `e > / #_` 去掉词首 e |
| `^+a` | `> a / #_` 词首加 a |

### 构形里按条件换字母 {#condition}

前缀、后缀、中缀、环缀和微调里可以写 `{条件:形式|条件:形式|默认}`：推导时按这个词条、这一格挑出一支，其余部分不变。条件写维度取值的名字或缩写；词条自己的语法特征（性、名词类别这类）和这一格的维度取值都算，同一个维度以这一格为准。

| 写法 | 意思 |
|---|---|
| `-{阴:g\|k}A` | 词条是阴性时用 g，否则用 k |
| `{性=阴:a\|o}` | 两个维度里有同名的取值时，写上维度 |
| `{阳,中:o\|a}` | 逗号：对上任一个就算 |
| `{阴+复:ae\|阴:a\|o}` | 加号：都要对上；从左往右第一支对上的算 |
| `-{阳:s}` | 没有默认那支、又都没对上时，这一段是空的 |

### 构形的「模板」{#pattern}

按词干的辅音、元音填进模板（设了正字法时按拼写的音数：主正字法里某个音位写作 th，th 就是一个辅音）：`C1`、`C2`… 是词干里的第 1、2… 个辅音，光写 `C` 依次取下一个；`V` 同理；其余字符照抄。例：`C1aC2aC3`、`maCCuC`。编号的意思与规则一致：编号指的是某一个具体的音。

### 中缀的插入位置 {#infix}

音段按拼写数：音位表里填了各正字法的写法、或者声明了多合字母时，th、eu 这类写法算一个音（重叠取头几个音也一样）。

| 写法 | 位置 |
|---|---|
| `V1`、`C1` | 第一个元音、辅音之后（`C2` 第二个……） |
| `C-1` | 最后一个辅音之后（负数从末尾数） |
| `<C-1` | 最后一个辅音之前（开头的 `<` 表示插在它前面） |
| `2` | 第 2 个音段之后 |
| `-1` | 倒数第 1 个音段之前 |

## 常见写法 {#recipes}

| 想做的事 | 写法 |
|---|---|
| 词末元音脱落 | `V > / _#` |
| 词末辅音脱落 | `C > / _#` |
| 元音间清塞音浊化 | `[ptk] > [bdg] / V_V` |
| 音节末的浊塞音清化 | `[bdg] > [ptk] / _σ` |
| 开音节里的元音延长 | `V > Vː / _σ` |
| 双写辅音变单写 | `C1C1 > C1` |
| 逆同化：前一个辅音变得跟后一个一样 | `C1C2 > C2C2 / V_V` |
| 鼻音部位同化 | `n > m / _[pbm]` |
| 软腭音在前元音前腭化 | 先定义 `{软腭}=k g`、`{龈腭}=tʃ dʒ`，再写 `{软腭} > {龈腭} / _[ie]`（多字母的成员要用长名音类，方括号按单个字符拆） |
| 两个辅音前增生元音 | `> e / #_CC` |
| 跨音节的辅音丛中间插元音 | `> ə / Cσ_C` |
| 同一个元音连写删一个 | `V1 > / V1_` |
| 元音之间插 j | `> j / i_V` |
| 词末 sk 换位成 ks | `sk > \ / _#` |
| 元音和谐 | 先定义 `Back=aou`、`Front=eöü`，再写 `A > a / Back?_`、`A > e / Front?_` |
| 词首辅音软化 | `m > w / #_` |
| 元音间的 p 变 b、别处的 p 变 f | `p > b?f / V_V` |
| 定倒数第二音节重音 | `ˈ = -2` |
| 拉丁式重音 | `ˈ = -2 {长元音} , -2 / _CC , -3` |
| 重读音节里的元音延长 | `V > Vː / ˈ(C)(C)_` |
| 非重读元音弱化 | `V > ə / σ(C)(C)_ - ˈ(C)(C)_` |
| 送气音后面的 a 变 e | 先写 `[+送气] = ph th kh`，再写 `a > e / [+送气]_` |
| 送气音在辅音前失去送气 | `[+送气] = ph th kh`、`[-送气] = p t k`，再写 `[+送气] > [-送气] / _C` |
| 删掉复合词边界 | `¢ > / _`（放在规则集最后） |
