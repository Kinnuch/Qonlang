# 千语集规则语言

音变、正字法转写、形态音位规则共用同一种规则语言。核心语法沿用 Kinnuch 的「自用音变姬」，
在其上加长名音类、注释、混写声明。音变姬的 Category / Replace / Rule 三个文件可以原样导入。

## 1. 一段文本里可以写什么

```
; 分号到行尾是注释；行首 # 也是注释（兼容旧文件）
V=aeiou                 ; 单字母音类
{Vlong}=ā ē ī ō ū       ; 长名音类，成员用空格或逗号分隔；不分隔则按字符拆
th|θ                    ; 多合字母：匹配前把 th 当成一个单位 θ，输出时换回
[+送气] = ph th kh       ; 特征：从这一行起规则里可以写 [+送气] [-送气]
ˈ = -2 / _CC , -3       ; 重音规则：到这一行时给词标上重音
-* 祖语                  ; 快照标记：记录此刻的词形，并给它起名
a > e / _i              ; 规则
-* 现代语
```

规则从上到下依次应用；每条规则在整个词内从左到右反复匹配。音类和多合字母声明可以写在任何位置，都对整段文本生效；特征和重音规则按行生效。

## 2. 快照标记 `-* 名称`

标记记录**到达该行时**的词形。因此第一行的标记就是输入本身，最后一行的标记就是最终输出。
测试台按标记名分列显示；「阶段对应的语言」把每个标记绑定到项目里的一门语言，供词库推导使用。

## 3. 一条规则

```
目标 > 替换 / 左0_右0 , 左1_右1 , … - 左排除_右排除 , 左排除_右排除 …
```

| 部分 | 说明 |
|---|---|
| 目标 | 可含音类、临时音类 `[abc]`、`()` 可选段。留空表示增生。写一个 `?` 分成满足 / 不满足环境两路（见下）。 |
| 替换 | 可含音类；目标里的第一个音类与替换里的音类按位置一一对应（`V > {Vlong}` 把第 n 个元音变成第 n 个长元音）。留空表示删除。`\` 换位（多于两个字符则整体倒序）。`2` 双写。 |
| 环境 | `_` 是目标所在位置，左右可留空但 `_` 不能省；没有 `/` 等于任意环境。多个环境用 `,` 分隔，**依次**应用（后一个环境看到的是前一个改完的词）。 |
| 排除 | 用 `-` 引出；命中排除环境的位置不变。几个排除用 `,` 隔开，落在任何一个里都不变。 |

**满足 / 不满足环境**：`x > a?b / Y` 满足 Y 的 x 改成 a、其余的 x 改成 b；`x1?x2 > a?b / Y` 满足 Y 的 x1 改成 a、不满足 Y 的地方 x2 改成 b；`x1?x2 > a / Y` 两路共用 a。a、b 可以是任何替换（音类对应、`\` 换位、`2` 双写、留空），满足时换位写 `\?2`。两路都按改之前的词判断、一次改完，重叠时按满足那一路。目标、替换里各只能有一个 `?`，环境里的 `?` 仍是跨位置；问号本身写 `\?`。

环境里可用的记号：

| 记号 | 含义 |
|---|---|
| `#` | 词首（左侧）或词末（右侧）；测试台、自动标音、整库演化、文字转写按空白逐词跑，每个词各有词首词末；构形流水线里整个形式算一个词 |
| `¢` | 复合词内部边界（只是一个普通符号，用完可以用 `¢ > / _` 删掉） |
| `(x)` | 可选 |
| `x\|y` | 多选其一，如 `#\|C_` |
| `?` | 跨位置：`_?m` 表示其后任意位置有 m |
| `[xyz]` | 临时音类 |
| `V`、`{Name}` | 引用音类 |
| `t.h` | 点号隔开两个字母，防止被当成多合字母 |
| `σ` | 音节边界（词首词尾、分隔符两边也算）；`\σ` 是字母本身 |
| `ˈ`、`ˌ` | 重读 / 次重读音节的开头（重音规则标上之后） |
| `[+名]`、`[-名 +名2]` | 特征引用，几个取交集 |

未在环境里特殊处理的字符原样进入正则表达式，因此 `|` 等可以直接用；反过来说，`+`、`*` 之类要避免。

## 3.1 音节、重音、特征（实现要点）

- **σ**：`ParseOptions.syllables`（`languageParseOptions` 从音系设置算出）加规则文本里的 V / C 音类给出切音节的单位与音节核；规则用了 σ 时 `apply.ts` 先 `annotate`，在音节之间、分隔符两边插非字符 U+FDD0，σ 编成 `(?:U+FDD0|^|$)`。
- **重音规则** `ˈ = 条目 , … | 分隔符 段`：`StressLine` 是一个 step，`assignStress` 去掉旧记号、按条目挑音节、在音节第一个音前插 ˈ / ˌ。之后的规则（以及用了 σ 的规则）编译成「音与音之间可隔着记号」的正则（`marks`），命中范围按原词坐标算，被换掉的那段里的记号按原位置放回（目标里自己写了 ˈ ˌ 的不放）。条目：`(n)` / `(n+)` 音节数，位置 `1 -2 * -*`，音节核（核里含有）`/ 环境 - 排除`，`_` 是音节核。
- **特征** `[+名] = 成员…`：按行生效（每行定义换一张新表），`[+a -b]` 取交集；只定义了一面时另一面编成「不是这些成员、也不是多字母成员中间那个字母」的单个音。替换里的特征按位置对应（要列了成员）。
- 输出带重音记号；构形、整库演化这些要当拼写用的地方在 `program.hasStress` 时 `stripStress`。正字法转音标用 `keepUnits`（`ipaUnits`）让 θ 这类本身是音标的多合字母内部符号不换回写法。

## 4. 示例

```
V=aeiou
{Vlong}=ā ē ī ō ū
C=ptkbdgmnlrsh
-* Proto
e > a / _h , h_          ; e 在 h 旁边变 a
V > {Vlong} / _#          ; 词末元音延长
h > / V_V                 ; 元音间 h 脱落
> e / #_[nm]C             ; 词首鼻音 + 辅音前增生 e
bm > \ / _                ; bm 换位为 mb
p > pp / V_V - _#         ; 元音间 p 双写，但词末不算
[+浊] = b d g
[-浊] = p t k
ˈ = -2 {Vlong} , -2 / _CC , -3   ; 拉丁式重音
[+浊] > [-浊] / _σ         ; 音节末清化
V > ə / σ(C)(C)_ - ˈ(C)(C)_   ; 非重读元音弱化
-* Modern
```

## 5. 导入其他格式

| 来源 | 处理 |
|---|---|
| 音变姬 `Category.txt / Replace.txt / Rule.txt` | 直接拼接，语义完全一致（有回归测试保证） |
| Lexicanter 发音规则 | `{a,b}` 联合 → `[ab]`；`^` → `#`；`∅` → 空 |
| Zompist SCA² | `目标/替换/环境/排除` → `目标 > 替换 / 环境 - 排除`；`*` → `?` |
