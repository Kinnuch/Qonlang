# 千语集规则语言（草案，M1 实现）

音变、正字法转写、形态音位规则共用同一种规则语言。核心语法沿用 Kinnuch 的「自用音变姬」，
在其上加长名音类、特征式写法、注释与分组。旧版规则文件可以原样导入。

## 1. 文件结构

```
-* 阶段名            ; 分组标题，对应一门语言到下一门语言（或共时规则集）
目标 > 替换 / 环境    ; 一行一条规则
; 以分号开头的是注释，行尾的 ; 之后也是注释
```

规则从上到下依次应用；每条规则在整个词内从左到右反复匹配。

## 2. 音类

在项目「音系」页定义，或在规则文件开头以 `名=成员` 声明：

```
C=ptkbdgmnlr
V=aeiou
{Vlong}=āēīōū          ; 长名音类用花括号
{Nasal}=[+nasal]        ; 由特征生成（M3 音位表就绪后可用）
```

- 单大写字母音类可直接写 `V`；长名一律写 `{Vlong}`。
- `[abc]` 是临时音类，只在本条规则里有效。
- 多合字母（如 `th`）在「音系 → 多合字母」里声明后，引擎在匹配前把它当一个单位。
  要按字面两个字母处理时写 `t.h`。

## 3. 一条规则

```
目标 > 替换 / 左0_右0 , 左1_右1 , … - 左排除_右排除
```

| 部分 | 说明 |
|---|---|
| 目标 | 可含音类、临时音类、`()` 可选段。留空表示增生。 |
| 替换 | 可含音类；目标与替换都是音类时按位置一一对应。留空表示删除。`\` 表示换位（多于两个字符则整体倒序）。`2` 表示对偶（重复目标）。 |
| 环境 | `_` 是目标所在位置，左右都可留空但 `_` 不能省。多个环境用 `,` 分隔，任一命中即可。 |
| 排除 | 用 `-` 引出，命中排除环境的位置不变。 |

环境里可用的记号：

| 记号 | 含义 |
|---|---|
| `#` | 词首或词末 |
| `¢` | 复合词内部的边界 |
| `(x)` | 可选 |
| `x\|y` | 多选其一 |
| `?` | 跨位置匹配：`_?m` 表示其后任意位置有 m |
| `[xyz]` | 临时音类 |
| `V` / `{Name}` | 引用音类 |

## 4. 示例

```
-* Proto to Stage 1
e > a / _h , h_          ; e 在 h 旁边变 a
V > {Vlong} / _#          ; 词末元音延长（V 与 {Vlong} 按位置对应）
h > / V_V                 ; 元音间 h 脱落
> e / #_[nm]C             ; 词首鼻音 + 辅音前增生 e
bm > \ / _                ; bm 换位为 mb
p > pp / V_V - _#         ; 元音间 p 双写，但词末不算
```

## 5. 与其他格式的对应

| 来源 | 处理 |
|---|---|
| 音变姬 `Category.txt / Replace.txt / Rule.txt` | 原样导入 |
| Lexicanter 发音规则 `th > θ` | 自动转换（`{a,b}` 联合 → 临时音类；`^` → `#`） |
| Zompist SCA² | 自动转换（`V/O/_#` → `V > O / _#`，`//` 排除 → `-`） |

## 6. 轨迹

测试区与批量推导会输出每条命中的记录：

```
sœcren → sœsren   (c → s)   第 6 行  [Proto to Stage 1]
```

点击一行即跳到对应规则。
