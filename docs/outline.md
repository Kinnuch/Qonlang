# 千语集 Qianyuji · 详细大纲（v1.1，已审批 2026-09-07）

> 名称：**千语集**（英文 slug `qianyuji`）。MIT 开源，独立仓库。Electron 桌面版为主，同一代码可作网页版。单 JSON 项目文件，另可导出为文件夹格式。界面中英双语，默认中文；浅色 + 深色第一版都做。
> 目标用户：所有造语者。先验语（a priori）、后验语（a posteriori）、单语、语系、自然语衍生都要能用。
> 瑟乌丝林语只是**测试语料之一**，用来验收「词源派语系」这条路径；另配一门结构完全不同的测试语验收通用性。

---

## 0. 设计原则

1. **不预设语言类型**。屈折 / 黏着 / 孤立 / 多式综合 / 词根-模板（闪语式）都能录；没有音变、没有祖语、没有范式的项目也能正常用。
2. **一切分类由用户定义**。词类、格、数、时、焦点、名词类别、方言、标签、缩写全部是项目数据，软件不内置任何一门语言的术语；只提供可选的「起步模板」。
3. **自动化只出草稿，人工永远可覆盖**。自动标音、自动屈折、自动 gloss 都能逐格改成不规则值，并标色区分。
4. **文字无关**。任意 Unicode 文字、多套正字法并列、RTL、组合字符、声调符号都按原样处理；排序按用户自定义字母表。
5. **数据可带走**。开放的 JSON 项目格式，任何表格都能导出 CSV，任何规则都能导出纯文本。
6. **双语界面**。中文 + 英文从第一版起，文案全部走字典文件。

---

## 1. 从 Lexicanter 汲取的与不采用的

**采用**：单文件项目 + 自动备份；词条多义项各带标签与方言；发音可标「不规则」；正字法转 IPA 的规则式转写；多正字法并列；音位配列驱动的随机造词；词源关系与整库演化；项目内文档页。

**不采用**：可拖拽自由布局（改为固定三栏）；20 套皮肤（只做浅色 + 深色）；云同步；它自己的规则方言（提供导入转换）。

---

## 2. 技术方案

**推荐：Web 优先 + Electron 壳**
- Svelte 5 + TypeScript + Vite。
- 引擎层纯 TS、无 UI 依赖、可单独测试：`sca`（音变）、`phon`（转写 / 音节 / 重音 / 声调）、`morph`（范式生成 + 反向索引）、`gloss`（分词与标注）。
- 存储：项目文件 `*.laim.json`；网页版用 File System Access API 读写本地文件，IndexedDB 做自动保存快照；桌面版用 Electron 打包（Windows / macOS / Linux 安装包，自动备份到用户数据目录）。
- 测试：Vitest。引擎层每个特性都有夹具（fixture）语言；瑟乌丝林语 236 条规则的回归测试只是其中一个夹具。

**备选**：Tauri（体积小，需装 Rust）；纯网页不打包。

## 3. 数据模型（项目文件）

所有「枚举值」（词类、槽位、特征、方言、标签）都是项目内的用户数据，不写死。

```
Project
├─ meta              名称、版本、时间戳、UI 语言、项目模板来源
├─ languages[]       一门或多门；可选 parent 形成语系树，也可完全平行
│   ├─ id, name, abbr, color, notes
│   ├─ phonemes[]    音位: symbol, features{}(用户可增删特征维度), orthography 映射
│   ├─ classes{}     音类/自然类: 名称 → 成员（支持长名，不限单字母）
│   ├─ digraphs[]    多合字母替换表
│   ├─ orthographies[]  名称、字体、方向(LTR/RTL/TTB)、双向转写规则
│   ├─ syllable      模板(用户定义如 (C)(C)V(C) 或按音类)、划分策略、是否启用
│   ├─ prosody       类型: none | stress | pitch | tone；规则或类别表或逐词手标
│   └─ phonotactics  合法 Onset/Nucleus/Coda + 非法序列 + 造词权重
├─ soundChanges[]    规则集，每条: from,to,env,except,note,enabled,group,
│                    fromLang→toLang（阶段）；一门语言也能只用来做共时转写
├─ categories{}      用户自定义的语法维度：如 案=[主,宾,与…], 数=[单,复], 焦点=[强,弱]…
├─ posList[]         词类，每个词类绑定 0 或 1 个范式
├─ morphemes[]       词根 / 词缀 / 附着词 / 小品词的统一表:
│   ├─ type          root | prefix | suffix | infix | circumfix | clitic | pattern(模板) | particle
│   ├─ form, allomorphs[](带环境), gloss(缩写), features{}, language, notes
├─ lexemes[]         词位
│   ├─ id, language, lemma, pos, features{}(名词类别等任意维度), tags[], dialects[]
│   ├─ senses[]      definition(多语言字段), examples[], tags[], register
│   ├─ etymology     { type: root|compound|borrowing|derivation|unknown,
│   │                  sources:[morphemeId|lexemeId|外部语言+词], protoForm, notes }
│   ├─ stems{}       用户自定义的词干槽（可为空）
│   ├─ forms{}       范式槽位 → { surface, derived, override, trace }
│   └─ pronunciations{ orthoId: { ipa, irregular } }
├─ paradigms[]       范式，按词类
│   ├─ dimensions[]  引用 categories，笛卡尔积生成槽位（可屏蔽部分组合）
│   └─ generators[]  每槽位的生成方式（见 4.6）
├─ sentences[]       例句: text, orthoTexts{}, translation, source, tags,
│                    tokens[] → { surface, analyses[], chosen, confirmed }
├─ phrasebook[]      短语/惯用语（Lexicanter 用户习惯保留）
├─ abbreviations{}   gloss 缩写表（含莱比锡标准预填，可改可加）
├─ docs[]            Markdown 页
└─ settings          主题、字体、缩写风格、分词符号、自动保存、导出模板
```

## 4. 功能模块

### 4.1 项目与语言
- 新建时选**起步模板**：空白单语 / 语系（祖语 + 子语言）/ 从 Lexicanter 导入 / 从 CSV 导入。模板只是预填空表，不锁定任何东西。
- 语言树视图：卡片式，可拖动挂接父子关系，也可全部平行。
- 全局搜索 Ctrl+K。

### 4.2 音系
- 音位表：按 IPA 辅音表 / 元音图布局点选，也可手输任意符号（含声调字母、点击音、非 IPA 符号）。
- 特征维度可增删（默认给出 IPA 标准特征集，可关掉）。
- 音类：长名或单字母都行；可从特征自动生成（如「所有浊阻塞音」）。
- 正字法 ↔ IPA 双向转写；多正字法并列实时预览。
- 音节划分：模板法或最大起首原则，可关闭（孤立语 / 音节文字自己带音节）。
- 韵律：无 / 重音（固定位置、权重规则、类别表、手标）/ 音高重音 / 声调（声调作为独立层附着在音节上）。
- 配列检查与随机造词（可设权重、可指定音节数范围、可排除已有词）。

### 4.3 音变
- 规则语言以音变姬语法为核心（阶段、多环境、排除、可选、临时范畴、跨位置、多选、换位、对偶、复合边界、词界），在此之上加：长名音类 `{Name}`、特征式写法 `[+voice]`（编译为音类）、注释行、规则分组折叠。
- 提供导入转换：Lexicanter 规则、Zompist SCA² 格式。
- 编辑器：语法高亮、错误提示、逐条开关、拖动排序、备注。
- 测试区：多词输入、各阶段中间形、逐条命中轨迹，点击跳规则。
- 批量推导 + 与词库现有形式对账（一致 / 不一致 / 新增，一键采纳）。
- 整库演化：把语言 A 推到语言 B，自动建立词源链接。
- 规则集可导出为纯文本，单语言项目也能用它做共时的正字法转写或形态音位规则。

### 4.4 语素库（词根 / 词缀 / 附着词 / 小品词）
- 统一表格，按类型过滤；每条带 gloss 缩写、特征、异体形与其出现环境。
- 词根可来自任意语言（含项目外的自然语，作为借词来源）。
- 检视器列出引用该语素的全部词位与例句；「用此语素造词」按钮。

### 4.5 词库
- 列表 + 检视器；按词类 / 标签 / 方言 / 自定义字母表排序过滤；多义项；每义项的释义字段可多语言（中文 + 英文并存或只填一种）。
- 词源：类型（词根 / 复合 / 借词 / 派生 / 未知）+ 来源链接 + 原始形 + 说明。
- 屈折形面板：只在该词类绑定了范式时出现；推导值可覆盖为不规则值，悬停看轨迹。
- 发音按当前正字法规则自动出，可标不规则。
- CSV 导入向导：列映射由用户拖选，映射可存为**用户自己的预设**再次使用；多列合并、按分隔符拆分、跳过区块都在向导里做。
- 重复 / 同音检测。

### 4.6 形态范式
- 用户定义维度（案、数、人称、时、体、焦点……任意名字），笛卡尔积得槽位，可屏蔽不存在的组合。
- 每槽位的生成器可选：
  1. **拼接**：词干 + 前缀 / 后缀 / 环缀 / 中缀（指定插入位置）；
  2. **拼接后跑音变**：指定从哪一阶段规则起算（形态音位规则）；
  3. **模板 / 交替**：词根-模板（C₁aC₂aC₃ 式）、元音交替（ablaut）、重叠（全部 / 部分）；
  4. **查表**：直接手填；
  5. **无**：孤立语词类不绑范式即可。
- 范式测试台：任选词位实时看整表；范式可复制、继承（不规则子类只改差异槽位）。
- 每槽位自动生成 gloss 标签（由维度值的缩写拼出，如 `NOM.PL`），可手改。

### 4.7 例句语料
- 录入原文、各正字法文本（可自动转写）、译文、出处、标签、自由行（如逐字直译、注释）。
- 自动 gloss：
  1. 分词：语素边界符号在设置里定义（默认 `-` `=` 空格，可加 `·` `'` 等）；
  2. 每个词在反向索引查：词位屈折形 → 语素库拼接（词缀剥离，支持多层）→ 已确认分析；
  3. 多解下拉，无解标黄可就地建词位或语素；
  4. 行数用户定义（默认：原文 / 语素切分 / gloss / 译文，可加正字法行、IPA 行）。
- 校正后的分析成为「已确认分析」，同形优先命中。
- 导出：莱比锡纯文本、HTML、Markdown、LaTeX（gb4e / expex）、**自定义模板**（用户写模板字符串，wiki 模板之类由用户自己配）。
- 语料统计：词频、未收录词、词位覆盖率。

### 4.8 短语簿与文档
- 短语簿：分类、短语、变体、发音（Lexicanter 用户迁移友好）。
- 文档：Markdown 页，支持 `[[词条]]` 引用与 gloss 块嵌入；导出 Markdown / HTML。

### 4.9 导入 / 导出
- 导入：CSV（映射向导）、Lexicanter `.lexc`、音变姬四文件、SCA² 规则。
- 导出：词典 HTML / Markdown / CSV / PDF（打印样式）；规则纯文本；例句各格式；整项目 JSON；**自定义模板导出**（词典条目模板 + gloss 模板），满足接入个人网站 / wiki / 输入法词典等各种下游。

### 4.10 IPA 与特殊字符面板（全局组件）
- 任何文本框按 Ctrl+I（或点输入框尾部的 ⌨ 图标）弹出面板，插入到光标处，不打断输入。
- 分页：肺部辅音（按 IPA 表布局）、非肺部辅音、元音（元音图布局）、附标、超音段（重音、长度、声调字母与声调数字）、其他符号（∅、→、·、¢、词界等造语常用符号）、**项目音位表**（当前语言已定义的音位排在最前）、**最近使用**。
- **附标自由组合**：先选基字，再逐个点附标（上、下、后附均可，可叠加多个），预览区实时显示组合结果与 Unicode 码位；组合结果可一键存为「常用组合」。
- 搜索：按名称或特征搜（如「浊」「卷舌」「鼻化」「voiced retroflex」）。
- 每个符号悬停显示名称、码位、IPA 特征；面板本身可停靠在检视器里常驻。

### 4.11 设置
- UI 语言、主题、字体（界面 / 语言数据 / 每正字法单独指定）、缩写风格、分词符号、自动保存间隔、备份份数。

## 5. 界面风格

- 三栏：56px 图标导航 / 列表与编辑区 / 360px 检视器（可折叠）。
- 浅色为主：暖白底 `#FAFAF7`、近黑文字、一种强调色（暂定青绿 `#0E9F8A`）；深色模式同结构。
- 界面字体 Inter + Noto Sans SC；语言数据默认 Gentium Plus，可按正字法指定。
- 圆角 8px、阴影极淡、8 倍数间距、斑马纹表格。
- 快捷键：Ctrl+S / Ctrl+K / Ctrl+N / Ctrl+Enter / 方向键导航。
- 无模态弹窗，删除用撤销条。
